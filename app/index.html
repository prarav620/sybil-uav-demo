VANET Guard

Catching lying vehicles
with machine learning and drones

Cars broadcast where they are and how fast they go, but nothing stops them from lying. This project detects misbehaving vehicles from their own history, and tests whether drones measuring signal direction can expose false positions.

The problem

Cars in a vehicular network broadcast a safety message about once a second: "I am car 42, here is my position, my speed and my heading." Other cars trust it. But a car can lie, and a Sybil attack is when one car pretends to be many. Receivers only see the claim, so a lie is hard to prove.

The idea: drones above the road measure the direction a radio signal really came from. Two or more drones can cross their directions to find the true position, and a big gap to the claimed position exposes a lie. Try it yourself in the Drone simulator.

How it works in four steps

Read the messages
3.19 million labelled records from the VeReMi Extension dataset.
Check each car's own story
Does the claimed speed match how far it actually moved? Is its timing and heading plausible?
Add drone evidence (simulated)
15 virtual drones measure signal direction; fusion estimates the true position.
Classify
A graph and a gradient-boosted classifier decide attacker or genuine.
Read this before quoting numbers. The dataset only contains the positions vehicles claim, not where they truly were. Everything that uses drone fusion rests on a documented simulation and is tagged SIMULATED. Numbers tagged MEASURED come from real dataset records only.

    Limits and honest caveats

    • Fusion results are simulated. The dataset has no true transmitter positions. Attackers were given a hidden true position (claimed minus a random 30-300 m offset), so the fusion gain is an upper bound, not a measurement on real attackers.
    • Every attack class is treated as position spoofing in that simulation, but some real attacks (speed or denial-of-service types) do not lie about position.
    • Coverage rule is not physical. Which drones hear a message is decided from the claimed position so that coverage cannot reveal the label; real radio does not work that way.
    • Not Sybil-only. The detector separates attack from genuine over 19 attack classes mixed together; class ids are not mapped to names.
    • The baseline uses sender history because the table has no receiver data, so it is stronger than a strict single-observer detector.
    • 20% of senders were used and the main tables use one fixed split; no hyperparameter tuning.
    • The drone simulator is an illustration, not a result: it shows the geometry of fusion with idealised bearings and simplified positions.
    • The live detector is a research prototype, unreliable on traces shorter than 10 messages or with blank noise columns, and not suitable for real safety decisions.
